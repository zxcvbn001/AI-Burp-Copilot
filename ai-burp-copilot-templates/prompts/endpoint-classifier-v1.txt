Analyze the following request and respond with ONLY one word:
- ENDPOINT: if this is an interactive business endpoint (API, form submission, authentication, etc.)
- STATIC_RESOURCE: if this is a static file (JavaScript, CSS, image, font, map file, etc.)
- UNKNOWN: if you cannot determine

Consider these factors:
- ENDPOINT characteristics: POST/PUT/PATCH methods, JSON/XML content type, API-like paths, query parameters, GraphQL endpoints, authentication endpoints
- STATIC_RESOURCE characteristics: common static file extensions (.js, .css, .png, .svg, etc.), content CDN paths, /static/, /assets/, /public/ paths

Respond with exactly one word: ENDPOINT, STATIC_RESOURCE, or UNKNOWN.
